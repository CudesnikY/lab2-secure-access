# ЛР №2. Клієнт-сервер віддаленого доступу до захищених даних

Дисципліна «Захист інформації», КПІ ім. Ігоря Сікорського.
Виконав: Бушний Андрій Андрійович, група ЗК-51мн. Варіант 1: шифр зсуву на 7 символів, CRC16.

## Вимоги
Python 3.8+, лише стандартна бібліотека (модуль `socket`, без мережевих фреймворків).

## Запуск
```
python server.py          # сервер: TCP і UDP порт 7700
python client.py          # клієнт: шукає сервер широкомовним UDP-запитом
python client.py --host 192.168.1.10   # підключення за відомою адресою
run.bat                   # Windows: сервер в окремому вікні + клієнт
```
Під час першого запуску сервер створює `users.json` з обліковим записом `ADMIN` без пароля:
пароль задається при першому вході з підтвердженням.

## Порт і протокол
- UDP 7700: запит `LAB2_DISCOVER` → відповідь `LAB2_SERVER 7700 <ім'я хоста>`.
- TCP 7700: пакет `| довжина 4 б | CRC16 2 б | JSON, зашифрований зсувом на 7 |`.
- Автентифікація: обмін ключами Діффі–Хеллмана (RFC 3526, група 14);
  пароль не передається, клієнт надсилає `CRC16(K || CRC16(сіль || пароль))`.

## Функції
| Роль | Функції |
|---|---|
| ADMIN | зміна пароля, додавання користувача, блокування користувача, список користувачів, завершення сесії |
| користувач | зміна пароля, отримання документа, завершення сесії |

У меню клієнта: `h` — довідка, `0` — завершення сесії. Три невірні паролі поспіль завершують сеанс.

## Файли

`server.py` — сервер · `client.py` — клієнт · `document.txt` — захищений документ.
